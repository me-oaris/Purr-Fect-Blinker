# Purr-Fect Blinker

A simple pcb designed for Hackclub Solder workshop. Cats are goddess, Neko wa Megami!
We must submit before themselves and serve for eternity!!!

**Materials Used**
x2 10µF Electrolytic Capacitor
x2 2N3904 NPN Transistor
x2 5mm LED
x2 220Ω Resistor
x2 47kΩ Resistor
x1 6mm Tactile Push Button
x1 CR2032 Battery Holder
x1 CR2032 3V Coin Cell Battery
